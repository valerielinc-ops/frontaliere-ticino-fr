Description complète

L'entreprise vous propose des activités d'assemblage exigeantes selon des spécifications précises. Vous travaillez de manière indépendante et responsable dans un environnement technologique. Pour notre client, nous recherchons une ou plusieurs activités

  • Pensée orientée vers la solution dans l'environnement technique
  • Connaissance de l'allemand pour le travail quotidien
  • Introduction attentive aux processus de montage
  • Travail dans un environnement de production techniquement caractérisé
