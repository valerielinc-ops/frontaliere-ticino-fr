The Position

As a Staining Software Engineer, Associate you will design and develop staining procedures in close collaboration with assay development. You develop software supplements that install staining procedures along with the underlying database elements required to support staining procedure(s) in the software application.

The Opportunity

  • Developing moderate-scoped procedures with senior engineering guidance to ensure cross-platform compatibility and optimal instrument performance.
  • Executing comprehensive manual and automated test scripts to validate software functionality and system reliability.
  • Adhering to company policies, Product Development Processes (PDP), and Work Instructions to ensure all engineering activities remain compliant.
  • Authoring and tracking documentation deliverables while identifying the appropriate reviewers and approvers to maintain project flow.
  • Managing Design Change Orders (DCOs), Document Changes (DCs), and PDP Document Approvals (DAs) within the Document Control System.
  • Maintaining the Software Design History File (DHF) by organizing documentation deliverables according to established best practices.
  • Facilitating project review meetings through professional presentations, minute-taking, and active tracking of action items to ensure on-time delivery.

Who You Are

  • You hold a BS degree or equivalent in a directly related discipline, or an
  • equivalent combination of education and experience
  • 2 years of related experience required. Experience in a regulated industry, desired

Behaviors, competencies, and qualities of the ideal applicant.

  • Basic organizational skills; ability to manage multiple concurrent projects and to plan project components to effectively report status to stakeholders.
  • Understanding or familiarity with project management tools (such as Smart Sheets, MS Project, or Trello).
  • Knowledge of creating software documentation for a medical device, software databases and/or scripting languages
  • Skilled with the use of word processing, spreadsheets, graphical and presentation software applications
  • Proficient in a document control system(s) (such as Agile).
  • Strong written and verbal communication skills.
  • Information Security and Data Privacy Fundamentals
