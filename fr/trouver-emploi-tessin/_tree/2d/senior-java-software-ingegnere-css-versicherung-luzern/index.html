Janvier 2028 CSS développe un nouveau système d'application dans un projet de terrain vert. Pour cela, nous vous recherchons comme Senior Java / JEE Software Engineer (h/f). Vous avez la possibilité de façonner activement l'architecture à partir de la base et de développer une solution durable avec une nouvelle équipe. Quand nous rencontrons-nous?

C'est à ça que ressemble ta vie quotidienne

  • Vous travaillez en étroite collaboration avec les équipes de développement, apportez vos idées et expériences et partagez vos connaissances. En même temps, vous développez continuellement votre expertise autour de l'EFAS.
